# arGus para Claude

Plugin de [arGus](https://argus.neptura.tech) para Claude Code y claude.ai: contratación pública de mínima cuantía en
Colombia, desde tu Claude.

> **En preparación.** Este repositorio todavía no se puede instalar. Cuando esté listo, arGus Web te mostrará el
> comando exacto y los prompts para empezar.

## Qué traerá

- **El conector de tu cuenta de arGus** (MCP remoto). Entras con tu correo de arGus; no hace falta token.
- **Skills** que usan solo ese conector: revisar si puedes presentarte a un proceso, guardar tu experiencia, armar la
  oferta con tu kit y hacer la revisión final antes de radicar.
- **Comandos** como `/argus:puedo <proceso>` y `/argus:oferta <proceso>`.

arGus no radica por ti: tú revisas, firmas y radicas en SECOP II.

## Qué no hay aquí

Ni datos de empresas ni código del motor de arGus. Este repositorio solo contiene el plugin.
